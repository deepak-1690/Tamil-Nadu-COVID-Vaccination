# Tamil Nadu COVID-19 Vaccination Centre Analytics

## 📊 Project Overview

This Power BI dashboard analyzes COVID-19 vaccination centres
across Tamil Nadu.

## 🎯 Objectives

- Analyze vaccination centres across Tamil Nadu
- Identify Government and Private vaccination centres
- Analyze vaccination centre locations
- Provide interactive filtering and visual insights

## 🛠️ Tools Used

- Excel
- Power BI
- Data Visualization

## 📌 Key Insights

- Distribution of vaccination centres
- Government vs Private centres
